# Inventions de communication — liste pour images Wikimedia

Objectif : sélectionner les inventions **principales** de communication à illustrer avec des photos/images Wikimedia Commons (licences libres : CC0, PD, CC-BY, CC-BY-SA).

Pour chaque item, un lien de recherche Commons est pré-fabriqué. Coche celles qui t'intéressent, on téléchargera ensuite le lot retenu dans `public/assets/inventions/` avec un fichier `credits.md` généré automatiquement.

**Notes rapides sur les licences :**
- **CC0 / PD** (domaine public) : à préférer, aucune obligation.
- **CC-BY** : mentionner l'auteur.
- **CC-BY-SA** : mentionner l'auteur ET propager la même licence sur tout produit dérivé (ok pour un jeu open source).
- Éviter : « fair use », **non free**, et tout ce qui a un bandeau restrictif.

## Workflow d'ajout d'une image dans le jeu

Une fois les images téléchargées dans `public/assets/inventions/xxx.jpg`, on peut :

1. Les afficher dans les **fiches pédagogiques** (`msg_xxx` dans `data.js`), en ajoutant un champ `image: "assets/inventions/xxx.jpg"` et un champ `credit: "Nom auteur (CC-BY-SA)"`.
2. Modifier le composant `Fiche.jsx` (ou l'équivalent) pour afficher l'image + attribution en petit sous la fiche.
3. Créer un écran « Crédits » accessible depuis le menu, listant tous les auteurs.

## À faire après validation

Une fois que tu as coché les images qui t'intéressent :
1. Je récupère chacune via l'API Wikimedia Commons
2. Je vérifie la licence (rejet si non libre)
3. Je télécharge dans `public/assets/inventions/{id}.jpg`
4. Je génère `public/assets/inventions/credits.md` avec les attributions requises

**Cocher ci-dessus les items voulus, puis « on y va ».**
